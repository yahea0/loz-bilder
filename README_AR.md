
# لوز بيلدر 0.2.0

نسخة مطورة من استوديو إدارة وتحرير مشاريع البرمجة على Android.

## الجديد
- واجهة رئيسية أكثر ترتيباً مع بحث عن المشاريع وقائمة إجراءات لكل مشروع.
- حذف المشروع نهائياً بعد رسالة تأكيد واضحة.
- محرر كود بترقيم أسطر وتمييز ألوان أساسي تلقائي لعدد كبير من الامتدادات.
- أدوات: بحث، استبدال، تراجع، إعادة، تعليق/إلغاء تعليق، زيادة/تقليل المسافة البادئة، الانتقال إلى سطر، وتحديد الكل.
- زر «حفظ والعودة» يحفظ الملف ثم يرجع تلقائياً إلى مستكشف المشروع.
- كشف أولي لنوع المشروع: Gradle/Android، Maven، Node، Python، C/C++، Rust، Go، Flutter، .NET، PHP، Ruby.

## البناء
يتضمن GitHub Actions لبناء APK الخاص بلوز بيلدر. راجع `.github/workflows/build-apk.yml`.

## تنبيه أساسي
محرك بناء المشاريع المستوردة محلياً غير منفذ بعد. دعم اللغات يتطلب تثبيت toolchain ومحولات بناء منفصلة؛ لا توجد أداة واحدة تبني جميع اللغات. زر البناء في هذه النسخة يعرض نوع المشروع والأدوات المطلوبة، ولا يبدأ بناءً مزيفاً. كما أن تلوين الكود قائم على قواعد لغوية خفيفة، وليس محللاً دلالياً كاملاً أو Language Server.
