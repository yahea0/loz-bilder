# لوز بيلدر — النسخة التأسيسية 0.1.0

مشروع Android أصلي بلغة Java. الهدف النهائي هو إنشاء بيئة تطوير وبناء Android مستقلة داخل الهاتف، من دون الحاجة إلى فتح Termux أو GitHub عند تعديل المشاريع اليومية.

## ما يعمل في هذه النسخة

- إنشاء مجلد مشروع محلي داخل مساحة التطبيق.
- استيراد مشروع من ملف ZIP.
- استيراد مجلد مشروع عبر منتقي ملفات Android.
- عرض المجلدات والملفات والتنقل بينها.
- فتح وتعديل وحفظ الملفات النصية مثل Java وKotlin وXML وGradle.
- إنشاء ملفات ومجلدات جديدة.
- إعادة تسمية الملفات وحذفها.
- تصدير المشروع إلى ZIP.
- حفظ المشاريع محلياً بين مرات تشغيل التطبيق.

## ما لم يُفعّل بعد

زر «بناء APK» حالياً يشرح حالة المحرك ولا يشغّل Gradle بعد. لن ندّعي أن البناء المحلي يعمل قبل دمج بيئة التنفيذ واختبارها على جهاز ARM64 حقيقي.

## طريقة البناء الأولية

يمكن بناء نسخة Debug من خلال Android Studio أو بيئة Android تدعم Gradle 8.9 وJDK 17 وAndroid SDK Platform 35.

يتضمن المشروع GitHub Actions workflow اختيارياً لبناء APK تجريبي عند رفع الملفات إلى مستودع. هذا مخصص لبناء تطبيق «لوز بيلدر» الأولي فقط؛ أما الهدف النهائي فهو أن تتم تعديلات المشاريع وتجميعها محلياً داخل لوز بيلدر.

## بنية محرك البناء المستقل المخطط

سيُضاف محرك منفصل داخل التطبيق، ويتكون من:

1. مدير حزم أدوات ينزّل حزمة ARM64 موثوقة مرة واحدة إلى مساحة التطبيق ويتحقق من SHA-256.
2. بيئة Linux userland خاصة بالتطبيق (root filesystem) وأداة تشغيل مناسبة لأندرويد مثل PRoot.
3. JDK وGradle وAndroid SDK command-line tools وBuild Tools متوافقة.
4. خدمة بناء أمامية مع سجل حيّ للمخرجات والأخطاء.
5. مجلد Gradle cache دائم لتقليل إعادة تنزيل الاعتماديات وإعادة العمل في كل بناء.
6. واجهة لاختيار Variant (debug/release) وإدارة keystore للتوقيع.

الإنترنت مطلوب في الإعداد الأول لتنزيل الأدوات والاعتماديات التي لا تكون موجودة محلياً. بعد اكتمال التهيئة، يكون بناء المشاريع المحلية ممكناً دون GitHub أو Termux، ما دامت متطلبات المشروع واعتمادياته متوفرة في الكاش.

## ملاحظات تقنية

- minSdk 26 وtargetSdk 34.
- Java 17.
- الوصول إلى الملفات الخارجية يتم عبر Android Storage Access Framework.
- استيراد ZIP يتحقق من المسارات لتقليل خطر Zip Slip.
- المشاريع تُخزن في مساحة التطبيق الخاصة حالياً؛ النسخة التالية ستضيف اختيار موقع تخزين خارجي دائم ونسخاً احتياطياً.
